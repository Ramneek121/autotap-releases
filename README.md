# ReTap releases

**New Mac:** [download ReTap Setup](https://github.com/Ramneek121/autotap-releases/releases/latest/download/ReTap-Setup.dmg) (1.1.3), open it, and drag ReTap Setup into Applications.

After that, nothing needs downloading by hand again:

- **ReTap Setup** updates itself when it opens (`setup.json`).
- **ReTap** on an iPhone or iPad offers each new build in Settings, and ReTap Setup always installs the newest one (`app.json`).

ReTap was called AutoTap until September 2026.

Every build is under [Releases](https://github.com/Ramneek121/autotap-releases/releases).
